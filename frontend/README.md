# خانه‌راه — Frontend

رابط فارسی و راست‌چین سامانه رزرو اقامتگاه با Next.js App Router، React و Tailwind CSS. اطلاعات از API واقعی پروژه FastAPI دریافت و در همان بک‌اند ثبت می‌شوند.

## اجرا

1. بک‌اند را طبق راهنمای `../backend/README.md` اجرا کنید:

   ```powershell
   cd ..\backend
   .\.venv\Scripts\Activate.ps1
   uvicorn app.main:app --reload
   ```

2. فرانت را در ترمینال دیگری اجرا کنید:

   ```powershell
   cd ..\front
   Copy-Item .env.example .env.local
   npm install
   npm run dev
   ```

3. سایت: `http://localhost:3000` — مستندات API: `http://127.0.0.1:8000/docs`

در صورت تغییر نشانی API، مقدار `NEXT_PUBLIC_API_URL` را در `.env.local` تغییر دهید. بک‌اند برای اجرای مرورگری فرانت روی پورت ۳۰۰۰، CORS را برای `localhost` و `127.0.0.1` فعال کرده است.

## بخش‌ها

- `/` صفحه اصلی، جست‌وجو و فیلتر شهر، نوع اقامتگاه، ظرفیت و تاریخ.
- `/accommodation/[id]` جزئیات، تصاویر، امکانات، قوانین، تقویم قیمت، ثبت مهمان، رزرو، پرداخت آزمایشی و امتیازدهی.
- `/my-bookings` مشاهده رزروها، لغو رزرو و مدیریت علاقه‌مندی‌های مهمان.
- `/admin` ورود مدیر و مدیریت اقامتگاه، کشور، شهر، امکانات و قیمت روزانه.

## سناریوی تست انتها به انتها

1. با اطلاعات `ADMIN_EMAIL` و `ADMIN_PASSWORD` تنظیم‌شده در فایل `.env` بک‌اند وارد `/admin` شوید.
2. کشور و شهر و حداقل یک امکان بسازید.
3. اقامتگاه را با تصویر و امکانات ثبت کنید.
4. برای تمام شب‌های یک بازه، قیمت روزانه با وضعیت «قابل رزرو» ثبت کنید.
5. در صفحه اصلی اقامتگاه را جست‌وجو و صفحه جزئیات را باز کنید.
6. تاریخ‌ها و تعداد مهمان را انتخاب و رزرو را ثبت کنید. اگر مهمان قبلاً در همین مرورگر ثبت نشده باشد، فرم اطلاعات مهمان نمایش داده می‌شود.
7. چرخه پرداخت آزمایشی به‌صورت خودکار اجرا می‌شود و رزرو تأییدشده در «سفرهای من» قابل مشاهده است.
8. علاقه‌مندی و امتیازدهی و لغو رزرو را هم بررسی کنید.

## محدودیت‌های API فعلی

- پرداخت با endpoint شبیه‌سازی بک‌اند انجام می‌شود و درگاه بانکی واقعی نیست.
- مدل مهمان در بک‌اند احراز هویت ندارد؛ شناسه مهمان برای تجربه فعلی در localStorage همان مرورگر نگه‌داری می‌شود.
- برای رزرو باید قیمت تک‌تک شب‌های بازه ثبت شده باشد. مبلغ نهایی از مجموع قیمت شب‌ها و تخفیف اقامتگاه محاسبه می‌شود.
- بک‌اند فعلی endpoint فهرست عمومی مهمانان یا ورود مهمان ندارد؛ بازیابی رزروهای مهمان به داده ذخیره‌شده در همان مرورگر وابسته است.
